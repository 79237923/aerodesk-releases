Abra esta página no computador onde o Eron Pro será usado.

Como instalar (leva 1 minuto)

  1. Clique em Baixar para Windows (botão acima).
  2. Abra o arquivo baixado (AeroDesk-Setup.exe).
  3. O Windows vai mostrar um aviso de segurança — isso é normal e esperado. Siga os 2 cliques mostrados abaixo.
  4. Pronto! O Eron Pro instala e abre sozinho.

O aviso do Windows (2 cliques e pronto)

Por que esse aviso aparece? O Windows mostra essa tela para todo programa novo de desenvolvedores independentes. Repare que ele diz “aplicativo não reconhecido” — ou seja, o Windows ainda não conhece o programa. Ele não está dizendo que é um vírus. Você só precisa fazer isso uma vez: depois disso, o Eron Pro abre e se atualiza sozinho, sem avisos.
